## 设计逻辑（与博彦版一致）

- **78 页 = 78 幕**，内容与页码严格对应原 PDF，零改动
- 每页效果图/页面作为**全屏背景**，套电影感运行引擎：
  - 缓慢推近（Ken Burns）+ 1.15s 交叉淡入切换
  - 暖金细线页眉（航柒书院 / 章节标签）、米白衬线字幕条、底部进度条 + 章节刻度、页码
  - 进入新章节时的**闪幕**（壹·私宴 / 贰·文化 / 叁·养生 …）
- 风格：Quiet Luxury — 暖灰纸 `#8d877c` / 米白 `#ece6da` / 哑光金 `#c6a877` / 深暖墨舞台 `#14110d`

## 操作

- `← →` 切换页 · `空格` 播放/暂停 · `F11` 全屏演示或录屏成片
- 底部按钮：编辑 / 上一页 / 自动播放 / 下一页

## 编辑模式（✎ 编辑）

- 点击**画面**：为当前页更换图片（如替换成更高清的效果图）
- 点击**字幕文字**：直接修改中/英文案
- 「⬇ 导出修改后的文件」：导出为新的单文件 HTML（图片自动 base64 内嵌）
