## 设计风格

- Quiet Luxury，与航柒书院同一套配色：深暖墨舞台 `#14110d` / 米白 `#ece6da` / 哑光金 `#c6a877`
- 每幕交叉淡入、进入章节的闪幕、暖金细线页眉、底部进度条 + 章节刻度、页码
- 纯版式设计，**无需图片也能演示**；作品幕可随时加图

## 操作

- `← →` 翻页 · `空格` 播放/暂停 · `F11` 全屏演示或录屏 · `E` 进入/退出编辑
- 底部按钮：编辑 / 上一页 / 自动播放 / 下一页 / 导出

## 编辑模式（✎ 编辑）

- 点击**任意文字**直接修改中/英文案（改动实时写入数据）
- 点击**作品卡片**为该项目换图；点击**画面空白处**为整幕加背景图
- 「⬇ 导出」：导出为新的单文件 HTML（图片自动 base64 内嵌）

## 待填写内容（当前为占位 `【…】`）
